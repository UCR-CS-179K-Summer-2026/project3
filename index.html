JSON Query Language System Design

JSON Query Language is a C++ project that retrieves values from JSON data using a path made of object keys and array indices.

The current system includes a query parser, a JSON parser, a command-line program, sample JSON files, and automated tests.

System Architecture

The project is divided into modules so that query parsing, JSON traversal, user input, and testing can be developed separately.

User Input | v main.cpp | +----------------------+ | | v v Query Parser JSON File Input | | v v Parsed Query JSON Text | | +----------+-----------+ | v JSON Parser | v Requested JSON Value

The query parser creates a structured representation of a query. The JSON parser follows object keys and array indices to return an actual value from JSON text. Full integration between both modules is planned for a later sprint.

Major Modules

Main Program

The main program is located in src/main.cpp.

Its responsibilities include:

  • Reading the JSON filename from the user.
  • Opening the selected JSON file.
  • Reading the file into a string.
  • Receiving a lookup path.
  • Calling the JSON parser.
  • Displaying the returned value.

Query Parser

The query parser is implemented in src/queryparser.h and src/queryparser.cpp.

It converts a query string into a recursive std::vector<JSONTypes> structure.

Example query:

FIND employees name

Parsed result:

{"FIND", "employees", "name"}

Nested query:

FIND {employees birthday month} day

Parsed result:

{"FIND", {"employees", "birthday", "month"}, "day"}

JSON Parser

The JSON parser is implemented in src/jsonparser.h and src/jsonparser.cpp.

It receives JSON text and a path represented as a vector of strings. Each string represents either an object key or an array index.

Example path:

std::vector<std::string> path = {
    "employees",
    "0",
    "name"
};

The parser interprets this path as:

  1. Find the employees key.
  2. Enter array index 0.
  3. Find the name key.
  4. Return the value at that location.

Module Interfaces

Check Whether a File Opened

int json_parser::isFileOpen(std::ifstream& json);

Return values:

  • 0 means the file opened successfully.
  • 1 means the file failed to open.

Example:

std::ifstream file("src/jsonFiles/employee.json");

if (json_parser::isFileOpen(file) != 0) {
    std::cerr << "File could not be opened";
}

Convert a JSON File to a String

std::string json_parser::jsonToString(std::ifstream& json);

This function reads the complete contents of a JSON file and returns them as a string.

Example:

std::ifstream file("src/jsonFiles/employee.json");

std::string jsonText =
    json_parser::jsonToString(file);

Parse JSON Data

std::string_view json_parser::parsejson(
    std::string_view json,
    const std::vector<std::string>& query
);

This function follows the requested path through the JSON text and returns the raw JSON value at that location.

Example:

std::vector<std::string> path = {
    "employees",
    "0",
    "name"
};

std::string_view result =
    json_parser::parsejson(jsonText, path);

Possible result:

"Laura"

If the requested path cannot be found, the parser returns an empty std::string_view.

The original JSON string must remain alive while the returned std::string_view is being used.

Parse a Query

void queryparser::parsequery(const std::string& query);

This function reads a query string and stores its parsed recursive structure.

Example:

queryparser::parsequery(
    "FIND {employees birthday month} day"
);

Retrieve the Parsed Query

const std::vector<JSONTypes>&
queryparser::getparsedquery();

Example:

const std::vector<JSONTypes>& parsed =
    queryparser::getparsedquery();

Algorithms

Query Parsing Algorithm

The query parser reads the query one character at a time.

  1. Characters are collected into the current token.
  2. Spaces separate normal tokens.
  3. An opening brace begins a nested group.
  4. A closing brace ends the nested group.
  5. Nested groups are parsed recursively.
  6. The result is stored as a vector of JSONTypes.

JSON Object Lookup

When the JSON parser reaches an object, it:

  1. Scans each quoted object key.
  2. Compares the key with the current path component.
  3. Skips values that do not match.
  4. Continues from the value belonging to the matching key.

JSON Array Lookup

When the parser reaches an array, it:

  1. Converts the current path component into an array index.
  2. Moves through the array values.
  3. Skips values until the requested index is reached.
  4. Continues parsing from that element.

Value Scanning

The parser can scan and skip:

  • Strings
  • Numbers
  • Booleans
  • null
  • Objects
  • Arrays

Optimizations

The current implementation scans the original JSON string directly instead of building a complete object tree.

Current optimization choices include:

  • Skipping JSON values that are not part of the requested path.
  • Stopping after the requested value is found.
  • Returning a std::string_view instead of copying the result.
  • Using recursive query structures instead of flattening nested groups.

Possible future optimizations include:

  • Reducing repeated scans of large JSON documents.
  • Adding indexed object lookup.
  • Reducing unnecessary string copies.
  • Validating query paths before JSON traversal.
  • Adding performance tests for large files.

Testing

The project uses GoogleTest to verify both the query parser and the JSON parser.

Query parser tests include:

  • Simple queries
  • Multiple query fields
  • Nested queries
  • Deeply nested queries
  • Empty queries
  • Whitespace edge cases
  • Array-index tokens

JSON parser tests include:

  • Reading a file into a string
  • Finding object values
  • Finding array elements
  • Reading nested values
  • Reading strings, integers, and decimal values
  • Handling a missing key

Example test:

TEST(JsonParser, FindsFirstEmployeeName) {
    std::ifstream file("../src/jsonFiles/employee.json");
    ASSERT_TRUE(file.is_open());

    const std::string jsonText =
        json_parser::jsonToString(file);

    const std::vector<std::string> path = {
        "employees",
        "0",
        "name"
    };

    const std::string_view result =
        json_parser::parsejson(jsonText, path);

    EXPECT_EQ(result, "\"Laura\"");
}

  • src/jsonFiles/employee.json

These files include:

  • Objects

  • Booleans
  • null

Planned Improvements

  • Connect parsed queries directly to JSON traversal.
  • Support complete query commands such as FIND.
  • Return typed values instead of raw JSON text.
  • Add clearer error messages.
  • Validate malformed JSON input.
  • Improve array-index validation.
  • Add integration and performance tests.
