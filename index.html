JSON Analytics Engine - System Design

System Architecture

JSON File ---> JSON Parser
                  |
                  v
Query ---> Query Parser ---> Query Engine ---> Result

Main Modules

JSON Parser

  • Reads JSON/JSONL files
  • Parses objects, arrays, strings, numbers, booleans, and null
  • Handles nested JSON

Query Parser

  • Reads the user query

Query Syntax

Supported operations:

FIND
FILTER
DISPLAY
ALLOF

Keys must use double quotes.

Array indexes do not use quotes.

FIND

Checks if a path exists.

FIND {"employees", 0, "name"}
Result: true

DISPLAY

Returns the value at a path.

DISPLAY {"employees", 0, "name"}
Result: "Laura"

ALLOF

Returns all values for a field in an array.

ALLOF {"employees", "name"}
Result: ["Laura", "Moustafa", "James"]

FILTER

Regex example:

FILTER {{"employees", "name"}, "^L"}
Result: ["Laura"]

Numeric range example:

FILTER {{"employees", "salary"}, 80000, 100000}

The range is inclusive.

Algorithms

Query Parsing

The parser reads the query character by character and tracks curly braces so nested query sections are handled correctly.

Path Traversal

Example:

DISPLAY {"employees", 0, "name"}

Traversal:

root -> employees -> index 0 -> name

Filtering

  1. Find the requested array.
  2. Check each item.
  3. Apply the regex or numeric range.
  4. Return matching results.

Edge Cases

The engine should handle:

  • Missing keys
  • Invalid array indexes
  • Empty arrays
  • Null values
  • Keys with spaces
  • Keys with commas
  • Invalid regex
  • Invalid query syntax
