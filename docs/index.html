JSON Query Engine

A C++20 query engine for searching and retrieving data from structured JSON documents. It combines a recursive query parser with direct JSON traversal so users can describe the data they want without manually navigating the file.

Get Started View on GitHub ↗

What It Does

The engine separates query processing from JSON processing. The query parser determines what operation the user requested, while the JSON traversal system locates the requested data inside objects and arrays.

Parse Queries

Converts raw query text into a structured representation while preserving nested groups, quoted tokens, commands, and filter information.

Traverse JSON

Searches JSON objects and arrays using requested keys and array indices while skipping values that are unrelated to the current lookup.

Execute Commands

Uses the parsed command to coordinate operations such as FIND and DISPLAY against the loaded JSON document.

Return Results

Returns the values or matches located by the traversal engine based on the structure of the user query.

Query Commands

The query language currently supports three primary commands.

FIND

Checks whether requested components or nested groups can be located in the JSON document.

Status: Implemented

DISPLAY

Navigates to requested JSON components and collects the values that should be returned.

Status: Implemented

FILTER

Filters values using regular-expression matching or numeric-range conditions.

Status: Implemented

Quick Example

Query a value from the first user in the loaded JSON document.

JSON Structure

{
      "users": [
        {
          "name": "Laura Chen",
          "score": 91.5
        }
      ]
    }

Query

DISPLAY {"users" { "0" { "name" }}}

Result

"Laura Chen"
