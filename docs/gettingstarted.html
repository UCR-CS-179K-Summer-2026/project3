Getting Started

Build the JSON Query Engine, load a JSON document, and run your first query.

Requirements

The JSON Query Engine is written in C++20 and uses CMake for project configuration. GoogleTest is used for the automated test suite.

  • A compiler with C++20 support
  • CMake
  • Git
  • GoogleTest for running the automated tests

1. Clone the Repository

git clone https://github.com/UCR-CS-179K-Summer-2026/project3.git
cd project3

2. Configure the Build

Create a separate build directory so generated build files remain separate from the source code. 

mkdir build
cd build
cmake ..

3. Build the Project

cmake --build .

After the build completes, the project executable can be run from the build output.

4. Load a JSON Document

The program reads a JSON document and then accepts query commands from the user. The repository includes example JSON files under the project’s JSON fixture directories.

Example data includes employee, product, university, Unicode, edge-case, and benchmark JSON files.

5. Run a Query

Once the JSON document is loaded, enter one of the supported query commands:

FIND

Check whether requested JSON components exist.

DISPLAY

Retrieve values from requested JSON components.

FILTER

Filter JSON values using supported matching conditions.
