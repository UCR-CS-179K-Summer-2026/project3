Features

The JSON Query Engine currently supports FIND, DISPLAY, and FILTER. Each command operates on a structured path through the loaded JSON document.

View Examples Getting Started

Supported Commands

FIND

Checks whether a requested path exists in the JSON document.

Status: Implemented

DISPLAY

Traverses a requested JSON path and returns its value.

Status: Implemented

FILTER

Searches entries using a supported filtering condition.

Status: Implemented

Understanding Query Paths

Query paths are written using nested braces. Each nested component describes another level of navigation through the JSON document.

For example: 

DISPLAY {"users" { "0" { "name" }}}

This path means:

  1. Locate the users array.
  2. Select array element 0.
  3. Locate the name field.
  4. Return its value.
Object keys and array positions are represented as path components inside the nested query structure.

DISPLAY

DISPLAY navigates through the JSON document and returns the value located at the requested path.

Example 1: Display a String

JSON Input

{
  "users": [
    {
      "name": "Laura Chen",
      "score": 91.5
    }
  ]
}

Query

DISPLAY {"users" { "0" { "name" }}}

Result

"Laura Chen"

The engine locates the users array, selects the first element, and returns the value stored under name.

Example 2: Display a Number

JSON Input

{
  "users": [
    {
      "name": "Laura Chen",
      "score": 91.5
    }
  ]
}

Query

DISPLAY {"users" { "0" { "score" }}}

Result

91.5

DISPLAY can return non-string JSON values as well, including numeric values.

Example 3: Display Metadata

JSON Input

{
  "meta": {
    "name": "big"
  }
}

Query

DISPLAY {"meta" { "name" }}

Result

"big"

FIND

FIND checks whether the requested JSON path exists. The command returns a Boolean result.

Example: Existing Path

JSON Input

{
  "users": [
    {
      "name": "Laura Chen"
    }
  ]
}

Query

FIND {"users" { "0" { "name" }}}

Result

true

The result is true because the first element of the users array contains a name field.

FILTER

FILTER searches entries using a condition applied to a selected field.

Regular Expression Filtering

This example searches the name field of users using the regular expression ^L.

In a regular expression, ^L means that the value must begin with the letter L.

JSON Input

{
  "users": [
    {
      "id": 1001,
      "name": "Laura Chen",
      "score": 91.5
    },
    {
      "id": 1002,
      "name": "James Smith",
      "score": 87.2
    }
  ]
}

Query

FILTER {"users" { "name" }} "^L"

Result

{
  "id": 1001,
  "name": "Laura Chen",
  "score": 91.5,
  ...
}

The engine checks the requested field and returns the JSON entry whose value satisfies the filter.

FILTER returns the matching JSON object rather than only the field used in the filtering condition.

Command Comparison

Command Purpose Typical Result
FIND Check whether a requested path exists. true or false
DISPLAY Retrieve a value from a requested path. JSON value
FILTER Return entries matching a condition. Matching JSON object
