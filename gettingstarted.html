Getting Started

Build the JSON Query Engine, load a JSON document, and run your first FIND, DISPLAY, or FILTER query.

Start Setup View Query Guide

Requirements

The JSON Query Engine is written in C++20 and uses CMake to configure and compile the project.

Before building the project, make sure the following tools are installed:

  • A compiler with C++20 support
  • CMake
  • Git
GoogleTest: GoogleTest is downloaded automatically through the project's CMake configuration, so users do not need to install it manually.

1. Clone the Repository

Start by cloning the project repository and moving into the project directory. 

git clone https://github.com/UCR-CS-179K-Summer-2026/project3.git
cd project3

2. Configure the Project

Use CMake to configure the project and create a separate build directory. 

cmake -S . -B build

This command reads the project's CMakeLists.txt, configures the build system, and places generated build files inside the build directory.

CMake may display developer or compiler warnings during configuration. A warning does not necessarily mean the configuration failed. Look for messages such as: 
Configuring done
Generating done
to confirm that configuration completed successfully.

3. Build the Project

Compile the JSON Query Engine and its supporting executables: 

cmake --build build

A successful build creates several targets.

build/json

The main command-line JSON Query Engine used to load JSON files and execute queries.

build/JSONQL

The automated GoogleTest executable used to run the project's correctness tests.

build/benchmark

The standalone performance benchmark executable.

4. Run the JSON Query Engine

From the root of the repository, start the command-line application with: 

./build/json

The program begins by asking which JSON file you would like to query.

5. Select a JSON File

At the filename prompt, enter the name of the JSON dataset you want to query.

For example: 

big

If the JSON file is opened successfully, the application displays the query prompt: 

JSON opened successfully.

Please enter Query

>

You can now submit FIND, DISPLAY, or FILTER commands against the loaded JSON document.

6. Run Your First Query

A DISPLAY query retrieves a value from a requested path in the JSON document.

Example: Display a User Name

Suppose the JSON document contains a users array whose first user has the name Laura Chen.

JSON Structure

{
  "users": [
    {
      "name": "Laura Chen",
      "score": 91.5
    }
  ]
}

Query

DISPLAY {"users" { "0" { "name" }}}

Result

"Laura Chen"

This query begins at the users array, selects array element 0, and then retrieves the value associated with the name key.

7. Retrieve Values with DISPLAY

DISPLAY follows a path through the JSON document and returns the requested value.

Example: Display a Numeric Value

Query

DISPLAY {"users" { "0" { "score" }}}

Result

91.5

The query navigates to the first element of the users array and returns its score value.

8. Check a Path with FIND

FIND checks whether a requested path or component exists in the JSON document.

Query

FIND {"users" { "0" { "name" }}}

Result

true

The result is true because the first object in the users array contains the requested name field.

9. Filter JSON Data

FILTER searches entries using a supported filter condition.

The following example applies the regular expression ^L to user names. In a regular expression, ^L means that the value must begin with the letter L.

Query

FILTER {"users" { "name" }} "^L"

Matching Result

{
  "id": 1001,
  "name": "Laura Chen",
  "email": "laura@example.com",
  "active": true,
  "score": 91.5,
  "roles": [
    "admin",
    "reviewer"
  ],
  "profile": {
    ...
  },
  "history": [
    ...
  ]
}

The engine searches the name field of entries in the users collection. Because Laura Chen begins with L, the matching user object is returned.

FILTER returns the matching JSON entry rather than returning only the value of the field used for the filter.

10. Run Another Query

After displaying a result, the application asks whether you want to submit another query. 

Query again?

(y/n)

>
  • Enter y to run another query against the currently loaded JSON document.
  • Enter n to stop querying.

Supported Commands

The current JSON Query Engine supports three main query commands.

FIND

Checks whether requested JSON components or paths exist.

Status: Implemented

DISPLAY

Traverses a JSON path and returns the requested value.

Status: Implemented

FILTER

Selects matching JSON entries using supported filter conditions.

Status: Implemented
